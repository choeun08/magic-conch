# 마법의 소라고동 🐚

질문을 하면 소라고동이 무작위로 답해 주는 파이썬 프로그램 (프로그램설계입문 팀 프로젝트)

## 실행
```
python main.py
```

## 화면 흐름 (화면 설계서 2.1)
1. 시작 화면: 소라고동을 클릭
2. 질문 화면: 질문을 쓰고 줄을 클릭 (또는 Enter)
3. 답변 팝업: 무작위 답변 → '다시하기'로 2번으로

## 파일 구조
| 파일 | 내용 |
|---|---|
| main.py | 화면 3개(tkinter), 줄 당기기 애니메이션, 답변 팝업 |
| answers.py | 답변 목록 (여기만 고치면 답변 추가) |
| test_random.py | 무작위성 시험 (1,000회) |
| requirements.txt | 음성 기능용 라이브러리 |
